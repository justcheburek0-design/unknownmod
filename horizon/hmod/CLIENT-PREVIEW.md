# UnknownMod 6.2.0 — client preview

Предварительный **только клиентский** релиз. Не является полноценным обновлением комплекта UnknownMod 6.1.1. Серверный мод и HorizonVoice для нового SDK не входят и не готовы. Полная сетевая анонимность, работа скинов, сохранение настроек и отдельных игровых механик сквозными тестами не подтверждены. Совместимость с прежним сервером 6.1.1 не проверена.

## Совместимость и установка

- Minecraft Java 26.3, Horizon `nightly-2026-11-22-f1bb66f`, commit `f1bb66f353cf67f2aa4665293fc75c8d91186fc7`.
- Проверено на Linux x86_64, launcher 0.2.107. Windows и другие версии Horizon не проверены.
- `.hmod` — ZIP с исходниками, не готовый исполняемый клиент. Нативный код выполняется с правами пользователя; перед разрешением сборки проверьте исходники.
- Установите и подготовьте указанную сборку Horizon официальным лаунчером. Создайте отдельный тестовый инстанс. Распакуйте `.hmod` в отдельную папку.
- Проверенный маршрут сборки из распакованной папки:

```sh
horizon-launcher native-build /path/to/unpacked-mod --instance YOUR_TEST_INSTANCE --version nightly-2026-11-22-f1bb66f --trust-native-code
```

Замените пути и имя инстанса своими. Лаунчеру нужны SDK и его управляемый Rust; первоначальная загрузка требует сети. Сборка выбирает полученную версию для указанного инстанса. Прямой импорт `.hmod` через интерфейс отдельно не проверен. Не устанавливайте старый `.hnmod` поверх этого клиента.

## Что изменилось

- Перенос legacy `.hnmod` в исходный `.hmod` с `horizon-mod.toml`, Cargo crate и lockfile.
- Публичные API-хуки для меню и отрисовки там, где это возможно; четыре оставшихся нативных миксина привязаны к указанному SDK.
- Отдельное меню по `U`, возврат в игру по `Esc`.
- Изменение формата не означает повышение FPS или усиление анонимности.

## Проверки

- 59 тестов ядра, успешная нативная сборка из исходников и чистой распаковки пакета.
- Точное соответствие 14 файлов архива исходникам, SHA-256 и отрицательные проверки повреждённых архивов.
- Реальный офлайн-клиент: открытие меню по `U`, закрытие по `Esc`, успешный выход (Vulkan). Каждая кнопка и сетевое поведение не проверены.
- Изолированная Linux-сборка с готовыми SDK/Rust-кэшами, но без собранного мода: 71.57 с. Повторное использование готовой сборки: 0.35–0.43 с, не повторная компиляция. Это не Windows-замер и не сравнение со старым SDK.

## Сервер и голос

Серверный перенос блокируют недоступные wire hooks (`E_MIXIN_NOT_REPLACEABLE`); см. локальный аудит, не поставляемый в этом preview. Голосовой SDK-probe не равен полноценному голосовому клиенту: интегрированного voice `.hmod` нет. Для обычной игры используйте прежний полный релиз до завершения интеграции.
