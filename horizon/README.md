# Переезд UnknownMod на Horizon 26.3

Horizon используется и на сервере, и на клиентах. Голос внутри игры проверен в обе стороны; нативная версия правил — UnknownMod 6.0. Сборка, правила, команды и расположение данных описаны в [UNKNOWNMOD.md](UNKNOWNMOD.md). Fabric-сборка 5.3 сохранена отдельно.

## Изолированный стенд

- `build/horizon/server`: отдельный сервер на `127.0.0.1:25567`, копия остановленного проверочного мира, op для `JustCheburek`.
- `build/horizon/resources/26.3`: ресурсы, подготовленные из локального Minecraft; звуки, языки и шрифты взяты из хранилища Modrinth. Эти файлы и Mojang jar не включать в git.
- `build/horizon/runtime`: официальный Horizon Nightly 2026-11-05, SHA256 архива проверен по GitHub; метаданные в `release-lock.json`.
- `sources.json`: точные коммиты движка, нативного relay, голосового клиента и horizon-mixins. Исходники движка для сборки находятся в настоящем git-checkout `build/horizon/verified-source`; инструмент сам проверяет HEAD.

## Голос

Сервер: официальный MIT `horizon-rust/horizon-mods/native/voicechat-server`, протокол 20, AES-GCM UDP, дистанция и измерение проверяются сервером. Клиент: MIT/BSD-3-Clause `Frenk1997/horizon-voice` со встроенным Rust Opus и Windows-аудио через cpal. Лицензии сохраняются в staged bundles; лицензия встроенного Opus находится в исходниках клиента.

Клиент исходно общается с Java-плагином через обычные custom payloads. `prepare-voice.py` добавляет нативный транспорт `horizon:mod_net` в обе стороны, сохраняя обычный транспорт для Java-серверов. В серверном адаптере spectator исключены из голосового состава, имена голосовых участников заменены на `JustPlayer`, чтобы голосовые состояния не раскрывали личности.

Запуск после успешной сборки:

```powershell
./horizon/start-server.ps1
```

Клиент устанавливается через официальный лаунчер: [инструкция](CLIENT-INSTALL.md). Старый автономный тестовый клиент выведен из использования. По умолчанию V — говорить, M — заглушить микрофон, G — настройки голоса. Проверить актуальные назначения в Options → Mods → Horizon Voice.

`build-voice.ps1` собирает оба нативных мода в один движок. Запускать после подготовки исходников и ресурсов; это пока не самостоятельный установщик на другом компьютере. Общесистемный Rust и пользовательские игровые профили не меняются.

## Проверки и границы готовности

- Официальный серверный relay: 15 тестов прошли, включая реальные UDP-сокеты, расстояние, измерения, группы, ограничения и повторные пакеты.
- `voice-proof --standalone`: два клиентских голосовых движка передали разные тоны через relay и Opus; каждый получил 76 800 сэмплов. Частотный анализ исключает локальное эхо. Микрофон и колонки в этой проверке не использовались.
- `node horizon/voice-game-clients.cjs`: две настоящие игровые сессии получают голосовые секреты через нативные сообщения и передают их Rust-проверке только по stdin. Секреты не печатаются и не сохраняются. Проверка требует уже запущенного движка с нативным relay, передаёт звук в обе стороны и анализирует декодированные тоны.
- Проверка через две игровые сессии на стенде выполнена успешно: каждый клиент получил 76 800 декодированных сэмплов чужого тона. Сборка обоих модов в Horizon прошла; настоящий графический клиент JustCheburek вошёл в мир и сообщил `[Voice] Connected (hold V to talk)`.
- Пользователь подтвердил слышимость тона в настоящем клиенте. После подключения физического микрофона тестовый игрок получил и декодировал 48 960 сэмплов его голоса (`peak_rms: 0.011678940061130289`). Проверка физических устройств в обоих направлениях пройдена.
- Ручной допуск: два клиента Horizon рядом слышат друг друга; на расстоянии и в разных измерениях не слышат; spectator не слышит живых и не передаёт им звук; повторный вход восстанавливает голос; микрофон и устройства вывода проверены в настоящем клиенте.

Без второго человека можно проверить устройства через тестового игрока:

```powershell
node horizon/voice-game-clients.cjs --tone   # VoiceA передаёт негромкий тон в течение минуты
node horizon/voice-game-clients.cjs --listen # VoiceA проверяет получение и декодирование вашего голоса
```

Запускать по очереди, находясь рядом с VoiceA в одном измерении. Во втором тесте говорить с удержанием V; проверка требует больше секунды декодированного аудио с ненулевой громкостью. Содержимое микрофона не сохраняется: в результате только число сэмплов и уровень сигнала. Успех автоматической передачи тонов не доказывает работу физического микрофона и колонок.

Обычный Horizon не загружает Fabric jar и Mixins. UnknownMod 6.0 собирается нативно вместе с голосом через `build-unknown.ps1`, после голосовой подготовки. `prepare-unknown.py` сохраняет базовые исходники и встраивает адаптеры профилей, скинов, боя, выходов, наблюдателей, команд и победы. Итоговый движок отделён от предыдущей голосовой сборки; автоматическая игровая проверка использует порт `25569` и отдельный мир.
