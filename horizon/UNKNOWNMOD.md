# UnknownMod 6.0 для Horizon 26.3

Нативный перенос правил эксперимента. Голос Horizon Voice входит в тот же движок; Fabric jar клиентам Horizon не нужен.

**Текущий порядок установки:** пользователь проходит установку самостоятельно в официальном лаунчере Horizon. Для клиента подготовлены `UnknownMod-6.0.0-client.hnmod` и `HorizonVoice-0.3.3-UnknownMod.hnmod`; см. [установку клиентских модов](CLIENT-INSTALL.md). Серверная часть продолжает работать в проверенном движке. Отдельный тестовый профиль убран в `build/horizon/retired-clients`, а `start-client.ps1` отключён. Описанный ниже прежний запуск клиента относится к тестовому стенду.

## Сборка и запуск

После подготовки закреплённых исходников и ресурсов из `sources.json`:

```powershell
./horizon/build-voice.ps1
./horizon/build-unknown.ps1
./horizon/start-server.ps1
./horizon/start-client.ps1 -Name JustCheburek
```

На этом компьютере готовый движок находится в `build/horizon/unknown-bin/horizon-client.exe`. Скрипты запуска автоматически выбирают его при наличии. `-VoiceOnly` выбирает предыдущую голосовую сборку без правил. Не заменять исполняемый файл работающей игры.

Тестовый игровой сервер: `127.0.0.1:25567`. Автоматический проверочный сервер использует отдельный мир и порт `25569`. Для него: `./horizon/start-server.ps1 -Directory C:/Artem/java/UnknownMod/build/horizon/unknown-test-server` и затем `node horizon/test-unknown.cjs`.

Ресурсы Minecraft остаются локальными и в git не входят. Сборка содержит настройки оптимизации для разработки; версии закреплены в `sources.json`. Это модифицированный движок Horizon, а не универсальный jar или установщик ресурсов на другом компьютере.

## Правила

- Скрытые игроки имеют общий ник, встроенный пользовательский скин, широкую модель рук, без плаща и подписи над головой. Сервер не передаёт оригинальные текстуры скрытого профиля.
- Раскрытие возвращает настоящий профиль и скин. Окончание таймера возвращает анонимность. При выходе охота приостанавливается; остаток сохраняется на диск, включая периодические снимки для аварийного перезапуска.
- Умолчания: раскрытие на 90 минут, проверка каждые 3 часа, минимум 3 живых участника. Наблюдатели и выбывшие не участвуют в выборе.
- Выбывание требует убийства другим игроком предметом с настоящим ником жертвы. Раскрытие не отменяет требование имени. Подходят любые переименованные предметы, а также имя выпущенного лука/арбалета или брошенного трезубца. Регистр не важен; внешние `[]`, `()` и `{}` допустимы, как в Fabric-версии.
- После принятого PvP-попадания оба игрока получают 30 секунд боя. Выход засчитывает обычную смерть с выпадением вещей; исключение происходит только при подходящем имени последнего входящего оружия. Смена предмета после попадания не меняет результат. Штатная остановка сервера штраф не вызывает.
- Выбывший остаётся наблюдателем после смерти и повторного входа. Голосовой сервер исключает наблюдателей из обмена голосом. Обычный текстовый чат, личные сообщения и команды эмоций отключены; внешние Discord-переговоры мод контролировать не может.
- Победитель — игрок или его scoreboard-команда, которому движок засчитал убийство дракона. Результат сохраняется; повторное убийство победителя не перезаписывает.

## Команды

Обычным игрокам доступна `/players`: «За последние 3 дня заходили» и «Давно не заходили». Источник — заданный список участников; если он пуст, whitelist; если и он пуст, история входов.

Операторам уровня 2 и консоли:

```text
/unknown status
/unknown reveal player [настоящий_ник]
/unknown reveal cancel [настоящий_ник]
/unknown reveal duration 90
/unknown reveal interval 3
/unknown reveal minplayers 3
/unknown reveal status
/unknown ghost настоящий_ник
/unknown restore настоящий_ник
/unknown nickname JustPlayer
/unknown roster Ник1 Ник2 Ник3
/unknown reload
```

`ghost` переключает состояние выбывшего; `restore` явно восстанавливает прежний режим. Пустой `reveal player` выбирает случайного доступного игрока, пустой `reveal cancel` завершает все охоты. Дополнительно доступны короткие формы `/unknown reveal Ник [минуты]`, `/unknown hide Ник`, `/unknown duration 90`, `/unknown interval 3`, `/unknown minplayers 3`.

Обычные административные `/give`, `/tp` и прочие команды используют настоящие профили. В ответах оператору сохраняются настоящие имена; анонимный профиль остаётся общим для всех клиентов.

## Состояние и проверки

Данные каждого мира: `<мир>/unknownmod/config.json`, `state.json`, `winner.json`. Перед заменой сохраняется `.json.bak`; запись идёт через временный файл и переименование. Некорректный JSON не перезаписывается значениями по умолчанию. Ручные правки конфигурации применяются через `/unknown reload`; текущие охоты сохраняют свой срок. Файлы состояния редактировать только на остановленном сервере.

`horizon/unknownmod/tests/scenarios.rs` проверяет бизнес-правила без графики. `horizon/test-unknown.cjs` проверяет реальное подключение ботов, пакеты профилей, команды, смерти, выход из боя, минутный возврат анонимности и настоящий удар по дракону. Результат успешного игрового прогона — `build/horizon/unknown-test-results.json` (21 проверка). Сценарий с драконом требует свежего состояния победы в проверочном мире.

`node horizon/test-restart.cjs prepare` останавливает проверочный сервер во время именного PvP; после его запуска `node horizon/test-restart.cjs verify` проверяет отсутствие штрафа за остановку, сохранение наблюдателя, победы, настроек и остатка охоты. Результат: `build/horizon/unknown-restart-results.json`.

Голос проверяется двумя виртуальными игровыми соединениями: `UNKNOWN_VOICE_GAME_PORT=25569` и `node horizon/voice-game-clients.cjs`. Режим `--expect-denied` с `UNKNOWN_VOICE_SERVER_DIR`, указывающим на проверочный сервер, отдельно проверяет отказ наблюдателю в доступе к голосу.

`start-qa-client.ps1` запускает отдельный невидимый клиент `UnknownQA` с собственными данными и отключённым звуком. Он используется для проверки отрисовки, не открывает профиль `JustCheburek`. Кадры проверки: `build/horizon/qa-anonymous-face.png`, `qa-revealed.png`, `qa-restored.png`.

Оригинальные скины клиентов без авторизации запрашиваются в отдельном потоке у Mojang; сеть не блокирует серверный тик. При недоступности Mojang используется обычный стандартный скин раскрытого профиля. При авторизованном входе сохраняются оригинальные свойства профиля из соединения.
