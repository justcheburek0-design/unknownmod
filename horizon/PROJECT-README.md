# UnknownMod для Horizon

Режим социальной дедукции для Minecraft 26.3: анонимные личности, временные раскрытия и выбывание при убийстве оружием с настоящим ником жертвы.

## Скачать и установить

[Скачать UnknownMod 6.1 для Horizon](https://github.com/justcheburek0-design/unknownmod/releases/tag/horizon-v6.1.0).

Для Windows x64 доступен готовый архив `UnknownMod-6.1.0-Horizon-Windows-x64.zip`: импорт через официальный лаунчер позволяет играть без локальной компиляции. Меню UnknownMod открывается клавишей **U**; команды вводить не требуется.

Нужны два файла из релиза:

- `UnknownMod-6.1.0-client.hnmod` — анонимные скины, переключение облика при раскрытии и интерактивное меню.
- `HorizonVoice-0.3.3-UnknownMod.hnmod` — голосовой чат для нашего сервера.

Скопируйте оба файла в `horizon-native-mods` внутри папки своей сборки в официальном лаунчере Horizon. Затем соберите клиент с модами в лаунчере. Полная [инструкция установки](horizon/CLIENT-INSTALL.md).

Проверенная версия клиента: **Horizon Nightly 2026-11-07, `2ebf00a`, Minecraft 26.3**. Для другой Nightly совместимость нужно проверять отдельно. Первый запуск нативной сборки может занять десятки минут.

## Правила

- Каждый видит свой настоящий скин; чужие скины, плащи и ники скрыты до раскрытия.
- По умолчанию раскрытие длится 90 минут, запускается каждые 3 часа при минимум 3 активных живых игроках. После таймера анонимность возвращается.
- Через 5 минут без действий игрок становится AFK и не учитывается в автоматическом ивенте. Статус скрыт; операторам доступен приватный отчёт `/unknown online` (или `/unknown afk`), порог меняется через `/unknown afktimeout <минуты>`.
- Для выбывания жертвы нужно убить её предметом, переименованным в её настоящий ник. Раскрытие не отменяет это условие. Обычные смерти не исключают игрока.
- После удара игрока действует 30-секундный бой. Выход засчитывает смерть; выбывание зависит от имени оружия последнего актуального входящего удара.
- Выбывшие становятся наблюдателями и исключаются из голосового общения с живыми.
- Побеждает игрок или команда игрока, убившего дракона.

Правила выполняет сервер UnknownMod. Одной клиентской установки для них недостаточно.

## Проверки и ограничения

В меню оператора есть журнал решений о смерти, выбывании и восстановлении. Игрок получает личное объяснение причины без раскрытия ника атакующего.

Сервер 6.1.1 заменяет чужие UUID случайными идентификаторами в игровых и голосовых сообщениях. Раскрытие возвращает имя и скин, сохраняя подставной UUID. Клиентские пакеты 6.1.0 совместимы с этим исправлением. [Проверки и границы защиты](horizon/PRIVACY-CHECKS.md).

[Идеи событий со скрытым совместным или боевым типом](horizon/EVENT-IDEAS.md) пока не включены на сервере.
