# Установка UnknownMod в Horizon

Каждый игрок видит свой настоящий скин. Чужие скины и плащи скрыты до раскрытия; после окончания раскрытия снова включается анонимный облик. Это различие задаёт сервер, обновлять клиентский пакет для него не требуется.

Сервер 6.1.1 также скрывает чужие UUID в игровых и голосовых сообщениях. Уже установленный клиент 6.1.0 совместим: переустановка и повторная компиляция не нужны.

Для Minecraft 26.3 / Horizon Nightly 2026-11-07 (`2ebf00a`). Это устанавливаемые нативные моды; импортировать готовый игровой клиент не нужно.

Для новой версии с интерактивным меню нужен сервер UnknownMod 6.1. Есть два способа установки.

## Готовый клиент без компиляции

Скачай `UnknownMod-6.1.0-Horizon-Windows-x64.zip`, распакуй архив и открой `Install-UnknownMod.cmd`. До этого в официальном лаунчере должна быть установлена и подготовлена Nightly 2026-11-07 (`2ebf00a`). Установщик проверяет SHA-256 бинарного файла и импортирует его как отдельную версию через официальный лаунчер. Игру он не запускает. После импорта перезапусти лаунчер и выбери импортированную версию.

В этой версии уже встроены UnknownMod и голос. Повторно компилировать эти же моды поверх готового клиента не нужно. Импортированная версия закреплена; обновление делается импортом нового архива. Сторонние нативные моды требуют отдельной сборки.

## Установка отдельных модов

Нужны два файла:

- `UnknownMod-6.1.0-client.hnmod` — анонимный скин, скрытый плащ, возврат оригинального профиля при раскрытии и интерактивное меню.
- `HorizonVoice-0.3.3-UnknownMod.hnmod` — голосовой клиент для нашего сервера, с выбором микрофона и устройств.

1. В лаунчере выбери сборку. Для первой проверки удобно создать отдельную чистую сборку кнопкой `+` рядом со списком сборок.
2. На «Главной» нажми кнопку с папкой, чтобы открыть папку выбранной сборки.
3. Открой или создай внутри неё папку `horizon-native-mods`.
4. Скопируй в неё оба `.hnmod`. Для стандартной сборки `Horizon` это `%APPDATA%\horizon\horizon-native-mods`.
5. Вернись во вкладку «Моды». Если новые файлы не появились, перезапусти лаунчер.
6. Запусти нативную компиляцию этой сборки и дождись её завершения. Установка Rust и первая компиляция занимают время; вручную собирать моды командами не требуется.
7. Нажми «Играть» и подключись к серверу UnknownMod. На компьютере разработчика тестовый адрес — `127.0.0.1:25567`; другим игрокам нужен адрес доступного им сервера.

Голос: удерживать `V`, `M` — отключение микрофона, `G` — меню голоса. Проверить назначения и устройство в настройках Horizon Voice.

Меню UnknownMod: `U` или «Настройки → Моды → UnknownMod». В нём доступны статус, таймеры и участники. У оператора также есть кнопки раскрытия, скрытия, возврата выбывшего, параметры раскрытий и приватный журнал. Возврат выбывшего требует второго подтверждающего клика. Назначение клавиши меняется в управлении.

Важное ограничение протокольной анонимности: [PRIVACY-CHECKS.md](PRIVACY-CHECKS.md).

Этот пакет — клиентская часть. Правила выбывания, охоты и победы выполняет сервер UnknownMod 6.0; на нашем проверочном сервере он уже установлен.

Совместимость дополнительных модов проверять отдельно. `Shulker Peek 0.1.0` в проверочной копии не применился к этой Nightly: его точка `horizon_client::lan::hub::Hub::stack` отсутствует. Для первого запуска используй чистую сборку с двумя указанными пакетами.

Пакеты не опубликованы в общем каталоге Horizon, поэтому поиск по названию пока их не находит. Файлы распространяются напрямую.
